## Featured Projects

### IST-KVS

A key-value store developed in C as part of the Operating Systems course at Instituto Superior Técnico.

The project combines several systems programming concepts, including:

* Client-server architecture
* Concurrent processing with threads
* Inter-process communication using named pipes (FIFOs)
* Non-blocking backups using independent processes
* Key subscriptions
* Signal handling and safe session termination

### PIC — Cifra de Ficheiros

A Java desktop application developed as part of the Integrated Course Project at Instituto Superior Técnico, focused on secure file encryption and decryption.

* Java & JavaFX
* AES-GCM
* PKCS#11 / SoftHSM2
* Role-based access control
* Audit logging

### Veterinary Hotel Management

Java application developed for the Object-Oriented Programming course, designed to manage a veterinary hotel.

The application handles animals, employees, habitats and vaccines, with data persistence through files.
